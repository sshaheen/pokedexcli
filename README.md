# PokedexCLI

## Description

- This is a command line app which allows users to:
  - Move around locations from the PokemonAPI
  - Try to catch and collect Pokemon
  - Get information on the Pokemon they have collected

I built this application as part of the Boot.dev course on HTTP Clients in Go  
I used the [PokeAPI](https://pokeapi.co/) to look up the locations and Pokemon using HTTP GET requests

## Learning Outcomes

Working with [mutexes](https://pkg.go.dev/sync#Mutex)  
Working with Go's [net/http package](https://pkg.go.dev/net/http)  
Working with [JSON](https://www.json.org/json-en.html) and Go's [encoding/json package](https://pkg.go.dev/encoding/json)
